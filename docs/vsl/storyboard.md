## Observações de direção
- **Soul ID primeiro:** se aparecer rosto (cenas 2, 3, 6), crie o personagem no `higgsfield-soul-id` e reutilize, senão cada clipe terá uma pessoa diferente.
- **Continuidade de paleta:** cenas 1–8 frias/neutras → cenas 9–12 quentes. Essa virada de temperatura é o gatilho emocional principal.
- **Sem rosto sempre que possível** nas cenas de dor: mãos, objetos e ambientes geram mais identificação (o lead se projeta) e são mais fáceis de manter realistas.
- Gerar cada clipe com 1–2s de margem além do trecho de áudio para dar respiro na montagem.
